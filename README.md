# ILM Test Center

A responsive, Quilgo-inspired online assessment dashboard for ILM The Contest Center. This is an original interface and starter prototype, not Quilgo's proprietary code or branding.

## Included
- Overview dashboard and activity visualization
- Tests list with create-test dialog
- Participant directory with add-participant dialog
- Results overview and sample submissions
- Question bank entry point for MCQ, short-answer and long-answer questions
- Reports and workspace settings
- Responsive sidebar and mobile layout

## Run
Open `index.html` in a browser, or enable GitHub Pages from **Settings → Pages → Deploy from a branch → main / root**.

## Important
This version is a front-end prototype. Data created in dialogs is held in browser memory and resets on refresh. Authentication, secure test delivery, timed sessions, proctoring, server-side grading, file storage, email notifications and a database are not connected yet. Add a secure backend before using it with real student records or examinations.
